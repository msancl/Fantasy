# Fantasy Football 25/26

Tiny starter site for testing GitHub Pages.

## Open Locally

Open `index.html` in a browser.

## Publish With GitHub Pages

1. Create a new GitHub repository, for example `fantasy-football-25-26`.
2. Upload `index.html` and `styles.css` to the repository root.
3. In GitHub, go to `Settings` -> `Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.

After GitHub finishes publishing, the site should be available at:

`https://YOUR-USERNAME.github.io/fantasy-football-25-26/`

The `#results` link will work like this:

`https://YOUR-USERNAME.github.io/fantasy-football-25-26/#results`
